# U4PLUS.github.io

U4PLUS 的个人主页站点，使用 [GitHub Pages](https://pages.github.com/) 免费托管。

## 站点地址

- https://u4plus.github.io/

## 本地开发

1. 克隆仓库：`git clone https://github.com/U4PLUS/U4PLUS.github.io.git`
2. 修改 `index.html`
3. 提交并推送：`git push origin main`（推送后 GitHub 会自动重新构建站点）

## 自定义域名（可选）

如需绑定自定义域名（例如 `www.example.com`），在仓库
Settings → Pages → Custom domain 中配置，并添加 `CNAME` 文件。
